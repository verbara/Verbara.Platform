## Why

C1 (`authwritequeue-deterministic-test-harness`, PR #102) eradicated the ~29 in-CI
synchronization fences and adopted `FakeTimeProvider`. Nothing prevents a future PR from
re-introducing the exact anti-pattern — a wall-clock `Task.Delay`/`Thread.Sleep` used as a
barrier to wait for fire-and-forget work — which is precisely what flaked under CI load. C2
(**C2 of the 4-deliverable program**) installs the regression guard that pins C1's win.

A grounding audit + design pressure-test (4 agents: 2 mechanism judges, a
completeness/false-dichotomy critic, an implementation-risk critic) corrected the original
framing on three load-bearing points:

- **The "CI grep-gate (Python)" first assumed was not the best mechanism.** The pressure-test
  surfaced a fifth option not in the original framing — an **in-process xUnit `[Fact]` source
  scan** — which dominates: it runs on every `dotnet test` (local **and** CI, not CI-only), it
  is itself a deterministic in-process test (dogfooding the program's own thesis), and it keeps
  the guard in the .NET domain instead of bolting on Python as a load-bearing gate for a
  .NET-only concern.
- **Build-time mechanisms (MSBuild `RoslynCodeTaskFactory`, `BannedApiAnalyzers`) have a fatal
  coverage gap:** they only run when a project compiles. `LoadTests` + `E2E.Harness` are not in
  the `slnx` and never build in CI, yet two legitimate `Task.Delay` sites live there — and any
  *future* fence added there would never be seen. The guard must scan **source**, by directory
  walk, not compilation output.
- **The ban-set was over-broad.** The post-C1 census found `GetAwaiter().GetResult()` (×40,
  fixture sync-over-async — a causal block, not a timed barrier), `.Wait()`/`.Result` (collides
  with `_executor.Result = …`, text-undecidable), and `Task.Yield` (cooperative, determinism-
  *friendly*) are **not** the flake class. Banning them would generate dozens of noise markers
  that train reviewers to rubber-stamp `// fence-allow:`, destroying its signal value.

## What Changes

**Mechanism — in-process `[Fact]` guard, Roslyn-parsed (chosen, "Option 1"):**

- New minimal test project `tests/Verbara.Platform.Governance.Tests` (inherits
  `IsTestProject=true` / `IsAotCompatible=false` / `IsPackable=false` from
  `Directory.Build.props`; **no `ProjectReference`** — it scans source files, not assemblies).
  Isolates the one new dependency (`Microsoft.CodeAnalysis.CSharp`) away from `Api.Tests`, and
  gives the `test-determinism` program a durable home for convention guards.
- The guard parses each test source with `CSharpSyntaxTree.ParseText` and matches
  `InvocationExpressionSyntax` for the **ban-set** — so a comment/prose/string mention of the
  API (the census has 9, incl. an XML-doc `<c>Task.Delay</c>`) is structurally a non-match and
  can never false-positive. It walks **all `tests/**/*.cs`** from a `[CallerFilePath]` anchor
  (covering `Identity.Redis.Tests`, `LoadTests`, `E2E.Harness` even though those assemblies
  never run in the default suite), excluding `obj/`, `bin/`, `*.g.cs`, `*.Designer.cs`,
  `*.generated.cs`, and `<auto-generated>` files.

**Ban-set (the rule: "is it a wall-clock barrier of a guessed fixed duration?"):**

- **INCLUDE:** `Task.Delay`, `Thread.Sleep`, `Thread.SpinWait`, `SpinWait.SpinUntil`, and a
  best-effort `Stopwatch`-elapsed spin-loop (`while`/`do` whose condition references
  `.Elapsed*`).
- **EXCLUDE (deliberately, documented):** `GetAwaiter().GetResult()`, `.Wait()`, `.Result`,
  `Task.Yield`, `ConfigureAwait` — each is causal-not-timed, text-undecidable, or determinism-
  positive.

**Allow mechanism — inline marker, no external file:** every legitimate delay carries
`// fence-allow: CATEGORY — reason` on the call's line or the immediately-preceding non-blank
line, `CATEGORY ∈ {SIMULATED-WORK, GUARD-TIMEOUT, SETTLE, LOOP-DRIVER}` (closed enum), `reason`
non-empty. Unknown category or empty reason fails the site. Co-located, line-shift-proof,
diff-visible for reviewer approval. The **11** census-identified legitimate sites are annotated
once (incl. converting the existing `WorkerResilienceTestHelpers.cs:29` prose note to the
structured marker).

**Liveness self-checks (the guard tests itself):** the guard asserts it scanned `> N` files
(guards the silent "found zero → green" failure), that a planted un-marked fence string trips
detection, that a prose mention does **not**, and that a correctly-marked site passes.

**Alias-introduction proxy:** the unresolvable false-negative (a `using static
System.Threading.Thread; … Sleep(0);` alias defeats any non-semantic scan) is mitigated by also
flagging introduction of a threading alias / `using static` in test source — a reviewable proxy
signal at near-zero cost, since it has no legitimate test use.

## Impact

- **Affected (new, test-only):** `tests/Verbara.Platform.Governance.Tests/` (project + the
  guard `[Fact]` + its self-tests); `Verbara.Platform.slnx` (+1 project);
  `Directory.Packages.props` (+`Microsoft.CodeAnalysis.CSharp`, test-only — never enters a
  shipped AOT host image, no `src/` reference).
- **Affected (test source, additive comments only):** the **11** legitimate `Task.Delay` sites
  across `Api.Tests` (2), `Identity.Redis.Tests` (4), `E2E.Harness` (2), `Flows.Tests` (1),
  `LoadTests` (2) — each gains a one-line `// fence-allow:` marker. No production source changes.
- **AOT:** none — the new project is test-only (`IsAotCompatible=false`); Roslyn never ships.
- **Cross-repo:** none (the ecosystem `TimeProvider` ADR is deliverable **C4**).

## Architectural Risk

- **Level:** LOW. Test-only; no production source, no shipped-image surface, no AOT impact.
- **Affected if wrong:** a mis-built guard either reds-out `main` (false positive — mitigated by
  the Roslyn syntactic match that cannot fire on comments/strings, plus the liveness self-tests)
  or lets a fence through (false negative — the accepted, documented limits are aliased usings
  [proxy-mitigated] and a call inside an interpolation hole [pathological, no legit use]).
- **Mitigation:** the guard is a **syntactic backstop**, explicitly *not* the program's primary
  defense — the durable controls remain the causal-completion seam, `FakeTimeProvider` adoption
  (C1), reviewer enforcement, and the **C4** `verbara-meta` `TimeProvider` ADR. A fence rebuilt
  from un-banned primitives (`SemaphoreSlim.WaitAsync(2000)`, `CancellationTokenSource(2000)` as
  a settle, a `Task.Run` busy-loop) is out of the syntactic guard's reach by construction and is
  recorded as such.

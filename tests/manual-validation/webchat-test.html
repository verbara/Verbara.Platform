3. Checklist de validación manual

Marcá cada caja a medida que la validás:

  • El widget cargó sin errores en la consola devtools (F12 → Console).
  • La burbuja aparece en la posición configurada.
  • Click en la burbuja abre el panel del widget.
  • El form de "iniciar conversación" pide nombre + email.
  • Iniciar conversación + enviar mensaje funciona sin errores.
  • El mensaje aparece en /agent/queue en otra pestaña (logueado como agente).
  • El agente acepta la conversación + responde.
  • La respuesta del agente llega de vuelta al widget en esta página.
  • Cerrar el panel del widget + reabrirlo preserva el hilo (no se pierde).
  • Refrescar esta página + reabrir mantiene la sesión (cookie funciona).

4. Errores comunes

Si algo no funciona, abrí la consola devtools (F12 → Console) y buscá:

  • Failed to load resource: net::ERR_CONNECTION_REFUSED → el host del Web está mal escrito o no está corriendo.
  • Access to fetch ... blocked by CORS policy → el origen de esta página no está en allowedOrigins del canal. Editar en /admin/channels.
  • WebSocket connection ... failed → puerto WSS bloqueado por firewall, o cert TLS inválido.
  • El widget carga pero no muestra burbuja → JS del widget tirando exception, ver Console.

Más detalles en 04-canal-webchat.md §6 CORS troubleshooting .

- [ ] **Step 2: Write ADR-0004 with these sections:**
  - **Status:** Accepted (executed during R5.2 Phase 0)
  - **Context:** Wave 2 audit (2026-04-25) surfaced four distinct patterns of tenant-stamping non-compliance across Pro packages. Per-package execution conventions need codification beyond ADR-0002's policy level.
  - **Decision:** Per-package conventions:
    - **Pro.EventStore:** events MUST include `TenantId` in payload; subscriber rejects events with empty/null `TenantId` via fast-fail with structured log + metric `eventstore.events.skipped{reason="missing_tenant"}`.
    - **Pro.CallAnalytics:** `CallAnalyticsEngine` injects `ITenantContext`; `ICompletedSessionStore.GetAsync(tenantId, sessionId)` signature locked; no `serverId` fallback for missing CDR — log + skip with metric `callanalytics.events.skipped{reason="missing_cdr"}`.
    - **Pro.Push.SignalR:** hub methods that subscribe to other tenants' state MUST validate ownership via `IAgentTenantResolver` (per ADR-0005); bridges require explicit `WithDefaultTenantId(string)` builder call (no implicit `"default"` fallback).
    - **Pro.Analytics:** builder method `AsteriskAnalyticsBuilder.WithSingleTenantMode(string defaultTenantId)` for opt-in single-tenant deploys; otherwise inject `ITenantContext`.
    - **Observability tag patterns:** `AsteriskSemanticConventions.Tenant.Id` mandatory in spans; meter `tenant_id` dimension required where cardinality permits (Pro packages have 3-100 tenants typical → permits).
  - **Consequences:** Same as ADR-0002 expansion — multi-tenant correctness; observability uplift; minor breaking-fix annotation for callers using empty fallback (justified per ADR-0002 P0).
  - **Alternatives considered:** (a) per-package ADRs separately rejected — too fragmented; (b) defer to documentation rejected — needs decision-record formalism for future onboarding.
  - **References:** ADR-0002, ADR-0005, R5.2 implementation spec, Wave 2 audit findings.

### Task P0.1.b — Author ADR-0005 (Platform) "Cross-tenant subscription validation in SignalR hubs"

**Files:**
- Create: `Asterisk.Platform/docs/decisions/0005-cross-tenant-signalr-subscription-validation.md`

**Mode:** foreground.

- [ ] **Step 1: Write ADR-0005 with these sections:**
  - **Status:** Accepted (executed during R5.2 Phase 0).
  - **Context:** Wave 2 audit B.15 — `PlatformHub.SubscribeToAgentPresenceAsync(string agentId)` accepts any `agentId` without validating that the agent belongs to the supervisor's tenant. Cross-tenant info leak. Need policy decision for resolution mechanism (JWT trust vs DB roundtrip vs cached resolver).
  - **Decision:** Implement `IAgentTenantResolver` with 5-minute `IMemoryCache` per-process; lateral invalidation via Pro.Push event `agent.tenant.membership.changed`. When `SubscribeToAgentPresenceAsync` is invoked, resolver returns the agent's tenant; if mismatched against the supervisor's tenant claim, hub throws `HubException("Cross-tenant subscription not authorized")` and emits audit entry `hub.cross_tenant_subscription_denied`.
  - **Consequences positive:** prevents cross-tenant info leak; cache amortizes DB cost (5 min × 100s of agents typical); lateral invalidation handles tenant-membership-change correctness.
  - **Consequences negative:** cache adds ~5-min staleness window for tenant-membership changes (acceptable for security purposes — moves are operationally rare).
  - **Alternatives considered:**
    - **(a) JWT claim trust-only:** rejected — tenant membership can change after token issuance; stale token is exploitable.
    - **(b) Database round-trip per call:** rejected — hot-path on every subscribe; latency + DB load.
    - **(c) Cached resolver (chosen):** balances correctness + performance.
  - **References:** ADR-0002, ADR-0004, R5.2 spec §B.15.

```csharp
public sealed class CachedAgentTenantResolver : IAgentTenantResolver
{
    private readonly NpgsqlDataSource _ds;
    private readonly IMemoryCache _cache;
    private static readonly TimeSpan CacheDuration = TimeSpan.FromMinutes(5);

    public CachedAgentTenantResolver(NpgsqlDataSource ds, IMemoryCache cache)
    {
        _ds = ds; _cache = cache;
    }

    public async Task<string?> GetTenantIdAsync(string agentId, CancellationToken ct = default)
    {
        if (_cache.TryGetValue<string?>($"agent-tenant:{agentId}", out var cached))
            return cached;

        await using var conn = await _ds.OpenConnectionAsync(ct);
        var tenantId = await conn.QuerySingleOrDefaultAsync<string?>(
            "SELECT tenant_id FROM asterisk_platform.agents WHERE agent_id = @AgentId",
            new { AgentId = agentId });

        _cache.Set($"agent-tenant:{agentId}", tenantId, CacheDuration);
        return tenantId;
    }
}
```

```csharp
public static class PlatformDataProtectionExtensions
{
    public static IServiceCollection AddPlatformDataProtection(
        this IServiceCollection services,
        Action<PlatformDataProtectionOptions> configure)
    {
        var options = new PlatformDataProtectionOptions();
        configure(options);

        var dataProtectionBuilder = services.AddDataProtection()
            .SetApplicationName(options.ApplicationName);

        if (options.UseEphemeralForTesting)
        {
            // No-op: in-memory keys
        }
        else if (!string.IsNullOrEmpty(options.FileSystemPath))
        {
            dataProtectionBuilder.PersistKeysToFileSystem(new DirectoryInfo(options.FileSystemPath));
        }
        else
        {
            // Default: DB-backed
            dataProtectionBuilder.PersistKeysToDbContext<PlatformDataProtectionDbContext>();
        }

        return services;
    }
}
```

```csharp
public sealed class RecoveryCodeService
{
    public IReadOnlyList<string> Generate()
    {
        var codes = new HashSet<string>();
        while (codes.Count < 10)
        {
            Span<byte> bytes = stackalloc byte[6];
            RandomNumberGenerator.Fill(bytes);
            codes.Add(Base32Encode(bytes)[..8]); // 8 chars
        }
        return codes.ToList();

    public string Hash(string code, string salt)

        using var sha256 = SHA256.Create();
```

```csharp
public sealed class RedisJtiRevocationCache : IJtiRevocationCache
{
    private const string KeyPrefix = "asterisk:jti:";
    private readonly IConnectionMultiplexer _redis;

    public RedisJtiRevocationCache(IConnectionMultiplexer redis) => _redis = redis;

    public async Task RevokeAsync(string jti, DateTimeOffset expiresAt, CancellationToken ct)
    {
        var ttl = expiresAt - DateTimeOffset.UtcNow;
        if (ttl <= TimeSpan.Zero) return;
        var db = _redis.GetDatabase();
        await db.StringSetAsync($"{KeyPrefix}{jti}", "1", ttl);
    }

    public async Task<bool> IsRevokedAsync(string jti, CancellationToken ct)
    {
        var db = _redis.GetDatabase();
        return await db.KeyExistsAsync($"{KeyPrefix}{jti}");
    }
}
```

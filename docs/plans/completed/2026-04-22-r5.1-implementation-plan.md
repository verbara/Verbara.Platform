## Goal

Ship a production-grade, demonstrably enterprise-ready release that closes the 4 production blockers discovered in code audit, materializes latent-value ops UI (5 items with 0% UI coverage today), and consolidates UI primitives to unblock subsequent parallelization. Zero atajos: multi-node first, observability intrinsic, audit everywhere, AOT clean, i18n complete, E2E verified.

## Architecture

Three phases execute in order:

1. **Phase 0 — UI primitives consolidation** (sequential, 1 subagent, ~4-6h): 5 Web primitives fragmentados/missing consolidados antes de lanzar paralelos que los reusarán.
2. **Phase 1 — Sprint 1 product-final** (mixed sequential/parallel, ~1.5-2 sem): 6 sub-items (S1.1–S1.6) con cross-cutting discipline aplicada bilateral.
3. **Phase 2 — Ops toolkit bundle** (4 paralelos tras Phase 0+1, ~1 sem): 4 sub-items (S2.1–S2.4) usando los primitives de Phase 0.

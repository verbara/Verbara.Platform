# ADR-0009: SLO baseline + alert severity model

**Status:** Accepted
**Date:** 2026-04-26
**Context:** R5.4 Production Validation Track A

## Context

R5.4 ships the first canonical SLOs + Prometheus alert rules. Two design
decisions need locking before S5.2/S5.3 execute:

1. How are SLO numeric targets chosen — aspirational or data-derived?
2. How are alerts classified for operator triage?

Premature aspirational SLOs cause alert fatigue + false confidence ("SLO met"
when actually under-load). 3-tier alert classification is industry standard
(Google SRE book) and matches the Prometheus convention.

## Decision

**SLOs are derived from S5.1 load test results, not aspirational.**

- S5.2 (`docs/operations/slos.md`) is written **after** S5.1 first run completes.
- Each SLO references the meter/counter that measures it (one of the 17 Pro
  meters or Platform meters).
- Targets use observed p50/p95/p99 from S5.1 with a 20% headroom margin.
- "v1 baseline" SLOs are explicitly conservative; "v2 enterprise" SLOs are
  documented as aspirational targets with hardware/scale assumptions.

**Alert severity model is 3-tier:**

- **P0 (page on-call):** API availability < 99% over 5min · JWT validation
  latency p99 > 500ms over 5min · License guard blocked > 1% of requests over
  10min · Retention service stalled > 1h
- **P1 (ticket within 24h):** SLO breach without P0 trigger · Circuit breaker
  open > 5min · Presence backlog growing for 15min · Audit write latency p99 >
  1s sustained
- **P2 (review weekly):** Capacity warnings (DB connections > 80% pool) · Slow
  queries (>500ms) · Retention dryrun divergence from purge counter

Each alert has a 1-paragraph runbook entry in `docs/operations/alerts-runbook.md`
with **what / why / first response**.

## Alternatives considered

- **Aspirational SLOs first, refine later** — rejected: causes alert fatigue;
  documented as anti-pattern in Google SRE Workbook.
- **2-tier severity (critical / warning)** — rejected: collapses P1/P2 distinction,
  forces on-call to triage everything as urgent.
- **5-tier severity (P0-P4)** — rejected: more granularity than triage process
  warrants at current scale; can be expanded if needed.

## Consequences

- **Positive:** SLOs reflect actual capability; alerts have meaningful severity
  for operator workflow.
- **Negative:** SLO publication is gated by S5.1 completion (sequencing
  dependency in Phase A).
- **Neutral:** Alert thresholds are tunable post-ship via PR to `alerts.yml`
  with operator approval.

## References

- R5.4 spec § "Track A" S5.2 + S5.3
- Google SRE Workbook chapter "Alerting on SLOs"
- Existing meter catalog: `Asterisk.Sdk.Pro/docs/architecture.md` § "Meter catalog"
```

using NBomber.CSharp;
using NBomber.Http.CSharp;
using NBomber.Contracts;

namespace Asterisk.Platform.LoadTests.Scenarios;

public static class JwtScenario
{
    public static ScenarioProps Build(string baseUrl)
    {
        var http = new HttpClient { BaseAddress = new Uri(baseUrl) };
        return Scenario.Create("jwt_issuance_validation", async ctx =>
        {
            var loginReq = Http.CreateRequest("POST", "/api/v1/auth/login")
                .WithHeader("Content-Type", "application/json")
                .WithBody(new StringContent("""{"username":"loadtest","password":"loadtest"}"""));
            var loginResp = await Http.Send(http, loginReq);
            if (!loginResp.IsError)
            {
                var meReq = Http.CreateRequest("GET", "/api/v1/auth/me")
                    .WithHeader("Authorization", $"Bearer {ExtractToken(loginResp)}");
                await Http.Send(http, meReq);
            }
            return loginResp;
        })
        .WithLoadSimulations(Simulation.Inject(rate: 2000, interval: TimeSpan.FromSeconds(1), during: TimeSpan.FromMinutes(2)));
    }

    private static string ExtractToken(NBomber.Http.HttpResponse resp) =>
        // Parse {"accessToken":"..."} — keep simple for load test
        System.Text.RegularExpressions.Regex.Match(resp.Payload?.Data?.ToString() ?? "", "\"accessToken\"\\s*:\\s*\"([^\"]+)\"").Groups[1].Value;
}

namespace Asterisk.Platform.Identity.Auth.Jwt;

/// <summary>
/// Represents one JWT signing key in the rotation pool. Old keys remain valid
/// for the rolling grace window so in-flight tokens don't break during rotation.
/// </summary>
public sealed record JwtKeyEntry
{
    /// <summary>Unique key identifier emitted as JWT `kid` header.</summary>
    public required string KeyId { get; init; }

    /// <summary>Symmetric key material (base64-encoded).</summary>
    public required string Key { get; init; }

    /// <summary>UTC timestamp when this key became active (signing).</summary>
    public required DateTimeOffset ActivatedAt { get; init; }

    /// <summary>UTC timestamp when this key stops being valid for validation.</summary>
    public required DateTimeOffset ExpiresAt { get; init; }

    /// <summary>True if this key is currently used to sign new tokens.</summary>
    public required bool IsActive { get; init; }
}

// src/Asterisk.Platform.Identity/Auth/Jwt/InMemoryJwtKeyStore.cs
using System.Collections.Concurrent;

namespace Asterisk.Platform.Identity.Auth.Jwt;

public sealed class InMemoryJwtKeyStore : IJwtKeyStore
{
    private readonly ConcurrentDictionary<string, JwtKeyEntry> _entries = new();

    public Task<IReadOnlyList<JwtKeyEntry>> GetAllAsync(CancellationToken ct = default) =>
        Task.FromResult<IReadOnlyList<JwtKeyEntry>>(_entries.Values.ToArray());

    public Task<JwtKeyEntry?> GetActiveAsync(CancellationToken ct = default) =>
        Task.FromResult(_entries.Values.FirstOrDefault(e => e.IsActive));

    public Task UpsertAsync(JwtKeyEntry entry, CancellationToken ct = default)
    {
        // If marking active, demote any currently-active to non-active.
        if (entry.IsActive)
        {
            foreach (var kv in _entries)
            {
                if (kv.Value.IsActive && kv.Key != entry.KeyId)
                    _entries[kv.Key] = kv.Value with { IsActive = false };
            }
        }
        _entries[entry.KeyId] = entry;
        return Task.CompletedTask;
    }

    public Task RemoveExpiredAsync(DateTimeOffset asOf, CancellationToken ct = default)
    {
        foreach (var kv in _entries)
        {
            if (kv.Value.ExpiresAt < asOf)
                _entries.TryRemove(kv.Key, out _);
        }
        return Task.CompletedTask;
    }
}

```csharp
// src/Asterisk.Platform.Identity/Auth/Jwt/JwtKeyRotationService.cs
using System.Security.Cryptography;
using Microsoft.Extensions.Options;

namespace Asterisk.Platform.Identity.Auth.Jwt;

public sealed class JwtKeyRotationService : IJwtKeyRotationService
{
    private readonly IJwtKeyStore _store;
    private readonly TimeProvider _time;
    private readonly JwtKeyRotationOptions _options;

    public JwtKeyRotationService(
        IJwtKeyStore store,
        TimeProvider time,
        IOptions<JwtKeyRotationOptions> options)
    {
        _store = store;
        _time = time;
        _options = options.Value;
    }

    public async Task<JwtKeyEntry> RotateAsync(CancellationToken ct = default)
    {
        var now = _time.GetUtcNow();
        var bytes = RandomNumberGenerator.GetBytes(_options.KeySizeBytes);
        var entry = new JwtKeyEntry
        {
            KeyId = Guid.NewGuid().ToString("N"),
            Key = Convert.ToBase64String(bytes),
            ActivatedAt = now,
            ExpiresAt = now.Add(_options.GracePeriod + _options.ActiveDuration),
            IsActive = true,
        };
        await _store.UpsertAsync(entry, ct);
        await _store.RemoveExpiredAsync(now, ct);
        return entry;
    }

    public async Task<JwtKeyEntry> GetActiveSigningKeyAsync(CancellationToken ct = default)
    {
        var active = await _store.GetActiveAsync(ct);
        return active ?? await RotateAsync(ct); // bootstrap on first use
    }

    public async Task<IReadOnlyList<JwtKeyEntry>> GetValidationKeysAsync(CancellationToken ct = default)
    {
        var now = _time.GetUtcNow();
        var all = await _store.GetAllAsync(ct);
        return all.Where(e => e.ExpiresAt > now).ToArray();
    }
}

// src/Asterisk.Platform.Identity.Redis/RedisJwtKeyStore.cs
using System.Text.Json;
using Asterisk.Platform.Identity.Auth.Jwt;
using StackExchange.Redis;

namespace Asterisk.Platform.Identity.Redis;

public sealed class RedisJwtKeyStore : IJwtKeyStore
{
    private const string Prefix = "platform:jwt:keys:";
    private const string ActiveKey = "platform:jwt:active";

    private readonly IConnectionMultiplexer _redis;

    public RedisJwtKeyStore(IConnectionMultiplexer redis) => _redis = redis;

    public async Task<IReadOnlyList<JwtKeyEntry>> GetAllAsync(CancellationToken ct = default)
    {
        var db = _redis.GetDatabase();
        var server = _redis.GetServer(_redis.GetEndPoints()[0]);
        var entries = new List<JwtKeyEntry>();
        await foreach (var key in server.KeysAsync(pattern: $"{Prefix}*").WithCancellation(ct))
        {
            var json = await db.StringGetAsync(key);
            if (!json.IsNullOrEmpty)
            {
                var entry = JsonSerializer.Deserialize(json!, IdentityJsonContext.Default.JwtKeyEntry);
                if (entry is not null) entries.Add(entry);
            }
        }
        return entries;
    }

    public async Task<JwtKeyEntry?> GetActiveAsync(CancellationToken ct = default)
    {
        var db = _redis.GetDatabase();
        var activeId = await db.StringGetAsync(ActiveKey);
        if (activeId.IsNullOrEmpty) return null;
        var json = await db.StringGetAsync($"{Prefix}{activeId}");
        return json.IsNullOrEmpty ? null
            : JsonSerializer.Deserialize(json!, IdentityJsonContext.Default.JwtKeyEntry);
    }

    public async Task UpsertAsync(JwtKeyEntry entry, CancellationToken ct = default)
    {
        var db = _redis.GetDatabase();
        var json = JsonSerializer.Serialize(entry, IdentityJsonContext.Default.JwtKeyEntry);
        var ttl = entry.ExpiresAt - DateTimeOffset.UtcNow;
        if (ttl > TimeSpan.Zero)
            await db.StringSetAsync($"{Prefix}{entry.KeyId}", json, ttl);
        if (entry.IsActive)
            await db.StringSetAsync(ActiveKey, entry.KeyId, ttl);
    }

    public Task RemoveExpiredAsync(DateTimeOffset asOf, CancellationToken ct = default) =>
        Task.CompletedTask; // Redis TTL handles expiration
}

using Asterisk.Platform.Identity.Auth.Jwt;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Http;
using Microsoft.AspNetCore.Routing;

namespace Asterisk.Platform.Api.Endpoints.Security;

public static class JwtKeyEndpoints
{
    public static IEndpointRouteBuilder MapJwtKeyEndpoints(this IEndpointRouteBuilder app)
    {
        var group = app.MapGroup("/api/v1/management/security/jwt")
            .RequireAuthorization(p => p.RequireClaim("permissions", "security.jwt.rotate"));

        group.MapPost("/rotate-key", async (IJwtKeyRotationService rotation,
            IAuditService audit, HttpContext ctx, CancellationToken ct) =>
        {
            var newKey = await rotation.RotateAsync(ct);
            await audit.WriteAsync(new AuditEntry
            {
                Action = "security.jwt.key_rotated",
                ActorId = ctx.User.FindFirst("sub")?.Value ?? "unknown",
                Resource = $"jwt-key:{newKey.KeyId}",
                After = $$"""{ "keyId": "{{newKey.KeyId}}", "activatedAt": "{{newKey.ActivatedAt:O}}" }""",
            }, ct);
            return Results.Ok(new { keyId = newKey.KeyId, activatedAt = newKey.ActivatedAt });
        });

        group.MapGet("/keys", async (IJwtKeyRotationService rotation, CancellationToken ct) =>
        {
            var keys = await rotation.GetValidationKeysAsync(ct);
            return Results.Ok(keys.Select(k => new { k.KeyId, k.ActivatedAt, k.ExpiresAt, k.IsActive }));
        });

        return app;
    }
}

// src/Asterisk.Platform.Core/DependencyInjection/HostedServicePromotionExtensions.cs
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.DependencyInjection.Extensions;
using Microsoft.Extensions.Hosting;

namespace Asterisk.Platform.Core.DependencyInjection;

/// <summary>
/// Promotes <see cref="IHostedService"/> registrations to also be resolvable
/// as the concrete type. Required when an <see cref="IHealthCheck"/> consults
/// the hosted service's heartbeat — DI must return the same singleton.
/// </summary>
public static class HostedServicePromotionExtensions
{
    public static IServiceCollection PromoteHostedServiceToSingleton<T>(this IServiceCollection services)
        where T : class, IHostedService
    {
        var existing = services.FirstOrDefault(d =>
            d.ServiceType == typeof(IHostedService) &&
            d.ImplementationType == typeof(T));
        if (existing is not null)
            services.Remove(existing);

        services.TryAddSingleton<T>();

        // Idempotent: only add factory forwarder if not already present.
        if (!services.Any(d =>
            d.ServiceType == typeof(IHostedService) &&
            d.ImplementationFactory is not null &&
            d.ImplementationType == null &&
            // Approximate matching: re-promotion is a no-op when factory already in place
            d.Lifetime == ServiceLifetime.Singleton))
        {
            services.AddSingleton<IHostedService>(sp => sp.GetRequiredService<T>());
        }
        return services;
    }
}

# Backup + Disaster Recovery Runbook

## Postgres backup strategy

### Daily full backup (pg_dump)

Sample cron entry (run on dedicated backup host or Postgres replica):
```
0 2 * * * /opt/asterisk/scripts/backup-pg.sh >> /var/log/asterisk-backup.log 2>&1
```

Retention: 30 days local + 90 days S3.

### Continuous WAL archive (PITR enabled)

Postgres `postgresql.conf`:
```
wal_level = replica
archive_mode = on
archive_command = 'aws s3 cp %p s3://asterisk-wal/%f'
```

Retention: 7 days WAL on S3 (sufficient for PITR within 7 days).

### Restore — full restore (disk loss)

1. Provision new Postgres instance with same version
2. `pg_restore -d asterisk_platform /path/to/backup.dump`
3. Update Platform.Api `ConnectionStrings:Postgres` to new host
4. Restart Platform.Api
5. Verify health: `curl /health/ready`

Estimated recovery time: 30 min for medium tier.

### Restore — PITR (corruption / accidental delete)

1. Identify timestamp of last good state (e.g., before bad migration)
2. Restore base backup
3. Configure recovery: `recovery_target_time = '2026-04-26 14:30:00 UTC'`
4. Start Postgres in recovery mode
5. Promote when target reached

Estimated recovery time: 1-2h for medium tier.

## Redis snapshot strategy

### RDB snapshot every 15 min

Redis `redis.conf`:
```
save 900 1
save 300 10
save 60 10000
```

Snapshot file: `/var/lib/redis/dump.rdb`. Backup to S3 every hour:
```
0 * * * * /opt/asterisk/scripts/backup-redis.sh >> /var/log/asterisk-backup.log 2>&1
```

### AOF append-only (durability)

Redis `redis.conf`:
```
appendonly yes
appendfsync everysec
```

### Restore Redis

1. Stop Redis: `systemctl stop redis`
2. Replace `/var/lib/redis/dump.rdb` with backup
3. Start Redis: `systemctl start redis`
4. Verify: `redis-cli ping` → PONG

Note: Identity.Redis JTI revocation cache will be empty after restore — users
with valid tokens may temporarily bypass revocation. Force re-auth if security
incident triggered the restore.

## Recovery scenarios

### Scenario 1: Disk failure on Postgres primary

→ Full restore from latest pg_dump + WAL replay. Use PITR script.

### Scenario 2: Accidental DELETE/UPDATE

→ PITR to timestamp before the bad statement. Use PITR script.

### Scenario 3: Node failover (cluster-aware)

If multiple Platform.Api nodes, traffic auto-shifts via load balancer. No
backup involvement. Verify with `curl /health/ready` from each node.

If only one Platform.Api node, downtime equals new node provision time.
Mitigate with HA config (medium+ tier).

set -euo pipefail

PG_HOST="${PG_HOST:-localhost}"
PG_USER="${PG_USER:-postgres}"

```bash
#!/usr/bin/env bash
set -euo pipefail

BACKUP_FILE="${1:-}"
PG_HOST="${PG_HOST:-localhost}"
PG_USER="${PG_USER:-postgres}"
PG_DB="${PG_DB:-asterisk_platform}"

if [ -z "$BACKUP_FILE" ]; then
  echo "Usage: $0 <backup-file.dump>"
  exit 1
fi

echo "[restore-pg] WARNING: This will DROP and RECREATE the $PG_DB database."
read -p "Type the database name to confirm: " confirm
[ "$confirm" = "$PG_DB" ] || { echo "Aborted."; exit 1; }

echo "[restore-pg] Dropping existing database..."
psql -h "$PG_HOST" -U "$PG_USER" -d postgres -c "DROP DATABASE IF EXISTS $PG_DB;"
psql -h "$PG_HOST" -U "$PG_USER" -d postgres -c "CREATE DATABASE $PG_DB;"

echo "[restore-pg] Restoring from $BACKUP_FILE..."
pg_restore -h "$PG_HOST" -U "$PG_USER" -d "$PG_DB" --no-owner --no-acl "$BACKUP_FILE"

echo "[restore-pg] Done. Verify with: psql -h $PG_HOST -U $PG_USER -d $PG_DB -c 'SELECT count(*) FROM tenants;'"

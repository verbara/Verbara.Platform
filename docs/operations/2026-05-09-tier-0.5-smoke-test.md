# Tier 0.5 Developer License — End-to-End Smoke Test Runbook

**First written:** 2026-05-09 (executed)
**Last revised:** 2026-05-10 (formalised as runbook)
**Owners:** Verbara maintainer; any operator preparing a Pro release that touches `Verbara.Sdk.Pro.Licensing`
**Reference:** [ADR-0018 Status update of 2026-05-09 (Trigger 7 met by Option B)](../decisions/0018-visibility-decision-3-private-now-public-on-trigger.md#status-update)

> **Purpose**: validate the **end-to-end** Tier 0.5 self-issuance flow (form on `verbara.io/developer-license` → Cloudflare Worker signs `.lic` → consumer-side `LicenseValidator.Validate` against the embedded `LicenseTrustAnchor.OfficialPublicKey` returns `Valid`) is operational. This is the artefact that closes [ADR-0018](../decisions/0018-visibility-decision-3-private-now-public-on-trigger.md) Trigger 7 by validating the *delivery mechanism* end-to-end without requiring a paying customer.

---

## When to run

- **Mandatory**: before publishing every Pro release that touches `Verbara.Sdk.Pro.Licensing` (most likely v2.3.x and beyond).
- **Recommended**: at least monthly to catch silent breakage of the verbara.io Worker, the Cloudflare D1 audit table, or the Resend email delivery.
- **Recommended**: after any change to `~/.verbara/keys/private.{pem,pkcs8.pem}` rotation or to the `VERBARA_LICENSE_SIGNING_KEY` Worker secret.
- **Optional**: as part of the quarterly drift-detection cron (the cron at `verbara-website` already verifies the public-key fingerprint matches what consumers validate against — this runbook adds an active e2e check).

## Prerequisites

- **.NET 10.0.100+ SDK** installed (matches `global.json` of all Verbara repos).
- **Pro NuGet packages** built locally and packed to `/media/Data/Source/Verbara/local-nuget-feed/`. At minimum `Verbara.Sdk.Pro.Licensing` at the version under test (≥ 2.2.0-pro).
- **Internet access** to `verbara.io` (form + Cloudflare Worker endpoint) and to your inbox to receive the email.
- A **valid email address** for the form (the issued `.lic` is delivered there).
- **No paid Pro license required** — this is the Tier 0.5 free Developer tier.

## Procedure

### Step 1 — Request a Tier 0.5 license

1. In a browser, open <https://verbara.io/developer-license/>.
2. Fill the form (name, email). The Cloudflare Turnstile widget will validate the request silently.
3. Submit. Expect a "Check your email" success message within ~3 seconds.
4. Open your inbox. The email arrives from `licensing@verbara.io` (via Resend) within ~30 seconds. The body contains an attached `.lic` file named `verbara-developer-<licenseId>.lic`.
5. Save the attachment to a working directory (e.g. `~/Downloads/`).

If the form rejects the submission with `429 Too Many Requests`, the rate-limit (KV-backed, 1 license per email per 24h) is in effect — wait or use a different email.

### Step 2 — Build the smoke-test program

Create `/tmp/verbara-trigger7-smoke/` with two files:

**`Program.cs`**:

```csharp
using Verbara.Sdk.Pro.Licensing;

if (args.Length == 0)
{
    Console.WriteLine("Usage: smoke <license.lic>");
    return 1;
}

var key = LicenseReader.Load(args[0]);
Console.WriteLine($"--- License contents ---");
Console.WriteLine($"  LicenseId : {key.LicenseId}");
Console.WriteLine($"  Licensee  : {key.Licensee}");
Console.WriteLine($"  Tier      : {key.Tier}");
Console.WriteLine($"  ExpiresAt : {key.ExpiresAt:yyyy-MM-dd HH:mm:ss zzz}");
Console.WriteLine($"  Features  : 0x{(int)key.Features:X3}  ({key.Features})");
Console.WriteLine($"  MaxAgents : {key.MaxAgents}");
Console.WriteLine($"  MaxNodes  : {key.MaxNodes}");
Console.WriteLine();

Console.WriteLine($"--- Trust anchor ---");
Console.WriteLine($"  Public key fingerprint: {LicenseTrustAnchor.OfficialPublicKeyFingerprintSha256}");
Console.WriteLine($"  Public key bytes (DER) : {LicenseTrustAnchor.OfficialPublicKey.Length} bytes");
Console.WriteLine();

var result = LicenseValidator.Validate(
    key,
    LicenseTrustAnchor.OfficialPublicKey,
    gracePeriod: TimeSpan.FromDays(7));

Console.WriteLine($"--- Validation result ---");
Console.WriteLine($"  Result: {result}");

return result switch
{
    LicenseValidationResult.Valid       => 0,
    LicenseValidationResult.GracePeriod => 0,
    _                                   => 2,
};
```

**`smoke.csproj`**:

```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net10.0</TargetFramework>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
    <RestoreAdditionalProjectSources>/media/Data/Source/Verbara/local-nuget-feed</RestoreAdditionalProjectSources>
  </PropertyGroup>
  <ItemGroup>
    <PackageReference Include="Verbara.Sdk.Pro.Licensing" Version="2.2.0-pro" />
  </ItemGroup>
</Project>
```

> Update the `Version` attribute to match the Pro release under test. If you are validating a release-candidate Pro package, ensure it has been packed to `/media/Data/Source/Verbara/local-nuget-feed/` first via `dotnet pack -c Release -o /media/Data/Source/Verbara/local-nuget-feed/` from the Pro repo root.

### Step 3 — Run the smoke test

```bash
cd /tmp/verbara-trigger7-smoke
dotnet run -- ~/Downloads/verbara-developer-<licenseId>.lic
```

`dotnet run` will restore + build + execute. First run takes ~15 seconds; subsequent runs ~3 seconds.

### Step 4 — Interpret the result

**PASS** (Trigger 7 stays ✅ GREEN):

```
--- License contents ---
  LicenseId : <a uuid>
  Licensee  : <your email>
  Tier      : Developer
  ExpiresAt : <today + 30 days>
  Features  : 0x1FF  (All)
  MaxAgents : 5
  MaxNodes  : 1

--- Trust anchor ---
  Public key fingerprint: f1b62a9d9b7d9d6a2c63cce18a04b8a6d0e9a0c58a3c4a6f60d4a10ee2f8c06b
  Public key bytes (DER) : 91 bytes

--- Validation result ---
  Result: Valid
```

Exit code `0`. Trigger 7 remains green.

**FAIL paths** and what they mean:

| Result | Meaning | Likely cause | Action |
|---|---|---|---|
| `Result: Invalid` | Signature did not verify | Worker is signing with a different private key than what `LicenseTrustAnchor` embeds; OR the `.lic` was tampered after issuance | Stop. Rotate keys + re-publish a Pro patch with the new public key embedded; re-issue any in-flight licenses |
| `Result: Expired` | License past `ExpiresAt + gracePeriod` | The `.lic` is older than 30 days + 7 days grace | Request a fresh license (Step 1) |
| `Result: GracePeriod` | License past `ExpiresAt`, within grace | Acceptable for the smoke test (still returns exit code 0) but indicates the license is stale | Optionally request a fresh license |
| `Format string can be only "G", "g", ...` | `Program.cs` Features format-spec mismatch | You used `{key.Features:X3}` instead of `{(int)key.Features:X3}` (Features is an enum) | Fix the cast in `Program.cs` |
| `Unable to load the service index for source ...` (NU1900) | NuGet registry unreachable | Private registry pre-configured but offline | Safe to ignore — `RestoreAdditionalProjectSources` falls back to the local feed |
| `LicenseException: License file ... corrupt` | The `.lic` is not valid JSON or missing required fields | The Worker emitted a malformed payload (regression in `verbara-website`) OR the file got truncated in email transport | Re-request; if reproducible, file an issue against the Worker |

### Step 5 — Document the run

Append a one-line entry to the operator log (private to the maintainer, e.g. `~/.verbara/operator-log.md`):

```
2026-MM-DD — Tier 0.5 smoke test PASS — Pro vX.Y.Z-pro — license <licenseId> issued, validated Valid
```

If FAIL: open an issue + halt the Pro release until resolved.
